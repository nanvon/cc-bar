**新增**
- 日粒度下新增本周 / 本月 / 本年三档时间范围，可以按天看柱子、但只统计这一个自然周期
- 周和月粒度也支持单周期上下文：选中本周 / 上周 / 本月 / 上月时，柱状图自动展开到近 14 个周期，所选那根全彩、前面的降透明

**修复**
- 用量柱状图在周 / 月粒度下 X 轴刻度和柱子对不齐，日粒度在天数较多时也会偏；现在三种粒度的刻度都和柱子居中对齐
- 统计页顶部的粒度和时间范围切换器，会随着当前粒度的选项个数忽宽忽窄、左右跳动；现在三个粒度宽度一致，右边缘固定
- 后台重新计算用量时，「正在重新计算用量…」提示出现和消失会把右侧的切换器推着来回平移

**优化**
- 周 / 月粒度的上下文窗口从所选周期起点往前推，首根柱子是完整的一周或一个月，不会因为被截断而天然偏矮
