遇到问题时可以在设置里导出一份脱敏日志发给开发者，不用再靠截图描述。

**新增**
- 设置 → 通用 → 诊断新增「导出诊断日志」：一键把运行日志和 App 状态打包成 zip 并在 Finder 中显示，可直接附到 GitHub Issue

  日志已脱敏，不含登录令牌、明文邮箱、对话内容、文件内容和项目名，账号只以一串哈希出现；导出前会先弹窗逐条说明包含和不包含什么，包里的 `summary.txt` 是纯文本，发送前可以自己先打开看一眼。App 不会自动上传任何内容。
- 同一分组新增「打开日志目录」和「详细日志」开关。日志存放在 `~/Library/Logs/CCBar`，自动轮转、总量约 8 MB 上限

**修复**
- 公司网络、VPN 或代理环境下，额度刷新失败时可能错误提示「凭据已失效，请重新登录」，误导用户去重新登录；现在能识别出是被代理或网关拦截，如实说明
- 断网时刷新失败的提示是一串英文报错代码，看不出是网络问题；现在统一说「网络不可用」
- 断网期间 Popover 顶部仍可能显示「刚刷新过」，与下方各服务的报错自相矛盾；现在会如实显示刷新失败和数据的时间
- 断网时服务状态圆点会继续用断网前的绿点声称「服务正常」，现在降级为灰色未知状态

**优化**
- 额度刷新失败的提示文案改为面向用户的说法，不再直接抛出技术错误串
