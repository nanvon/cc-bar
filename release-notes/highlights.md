最近一个月新增的功能，你可能还没用过：

- 额度快用完时发系统通知，在「设置 → 通用 → 额度提醒」开启
- 额度页「历史周期」可切换 5 小时 / 周，比较用满预估与实际用量
- 弹出面板可查看最近对话的用量，点击打开对话详情
- 在「检查更新…」里查看更新内容，下载后自动安装并重启
- 在「设置 → 数据与刷新 → 网络代理」给 CCBar 单独指定 HTTP 或 SOCKS5 代理
- 在「设置 → 服务与账号」拖动服务，调整菜单栏和统计页顺序
- 统计页支持 Antigravity 的用量、对话和项目
- 在「设置 → 服务与账号」开启 OpenCode Go，查看 5 小时、周、月额度
- 统计页可比较各模型的首字延迟和输出速度，在概览「用量构成」切到「模型」
