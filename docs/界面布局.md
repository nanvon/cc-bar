## 1. Popover

### 1.1 整体规格

| 项 | 值 |
|---|---|
| 宽 | 340pt(固定) |
| 高 | auto;随启用 Provider 数量增长,零服务 ~110pt(提示空状态) |
| 圆角 | 18pt(`NSPopover` 系统提供,不自绘) |
| 材质 | `.popover`(系统) |
| 锚点 | 菜单栏图标下方,7pt arrow notch 朝上 |
| 出现动画 | 系统默认(`MenuBarExtra(.window)` 提供) |

### 1.2 结构总览(top → bottom)

│   "Usage"  13pt 600                                       │
│   "用量 · refreshed 32s ago"  11pt secondary              │
│                          ● [↻] [📊] [⚙] [⏻]               │
├───────────────────────────────────────────────────────────┤  ← 0.5pt separator full
│ Codex block                                  14/16pt     │
│   ▢ Codex                                   ● 6pt status │
│     OpenAI · Plus                                         │
│                                                           │
│   42%    ▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░  (7pt bar)             │
│   5HOUR    2h18m          today  $12                      │
│            重置            this week $18                  │
├───────────────────────────────────────────────────────────┤  ← 0.5pt separator inset 16
│ OTHER CODEX ACCOUNTS · 其他 Codex 账号         3           │  ← 仅有导入账号时出现
│   codex-work     5H ▓▓▒░░  18%  3h 41m                   │

│   codex-team     5H ▓▓▓▓▓▒  74%  0h 52m                   │
│                  WK ▓▓▓▓▒░  48%  4d 02h                   │

> 与原型差异:已移除独立 footer。原 footer 上的「Open Statistics」按钮 和「refresh」按钮合并为 header 右侧的一级图标按钮,刷新进度通过刷新图标自身旋转表达,不再单独画进度条。

### 1.3 Header

- **容器**:HStack(spacing 4),padding `14pt 上 / 12pt 左右 / 12pt 下`(到 separator)。
- **左侧**(VStack,line-height 1.1):
  - `Usage` — 13pt .semibold
  - `用量 · refreshed 32s ago` — 11pt secondary
    - `refreshed {n}s ago` / `{n}m ago` / `{n}h ago`,取所有已启用主 Provider 中**最近**一次成功时间;从未成功但有错误时显示 `refresh failed · 刷新失败`,两者都没有时显示 `waiting… · 等待数据`。由 `TimelineView(.periodic(by: 1))` 每秒重算,Popover 不可见时不调度。
- **右侧**(HStack,spacing 4):
  1. **status dot** — 7pt 圆点(live/stale/offline),颜色按 设计风格 §4.3,hover tooltip `Live · 在线` 等。
  2. **Refresh** — `arrow.clockwise` 13pt,按钮 `26pt × 22pt` 圆角 5pt,hover 浅灰背景(`Color.primary.opacity(0.08)`)+ 手型光标。点击触发 `appState.refreshNow()`,图标旋转 360° / 700ms ease-in-out。**不禁用**:`AppState.refreshNow()` 内部已做 in-flight 去重,不会重复发请求,刷新开始后由 `isRefreshing` 驱动转圈。
  3. **Open Statistics** — `chart.bar.xaxis` 13pt,同尺寸按钮。点击先设 `appState.mainTab = .stats` 再 `openWindow(id: "main")`,Popover 关闭。
  4. **Settings** — `gearshape` 13pt,同尺寸按钮。点击先设 `appState.mainTab = .settings` 再打开主窗口,与 ⌘, 命令行为一致,总是落到设置 tab。
  5. **Quit** — `power` 13pt,同尺寸。点击 `NSApp.terminate(nil)`,hover tooltip `Quit · 退出`。

> 设计依据:用户反馈一级操作(设置 / 刷新 / 统计 / 退出)藏在 kebab + footer 里不直观,统一拉到顶部图标行,降低点击层级。Quit 早期收在 `ellipsis` 菜单需要点两次,后续也拉平为一级图标。

- **separator**:0.5pt 全宽,`.separatorColor`。

### 1.4 服务 block（主 Provider 共用结构）

整个 block 用 `14pt 上下 / 16pt 左右` padding。

#### 1.4.1 Service header row(HStack,gap 9pt)

| 元素 | 规格 |
|---|---|
| 服务 tile | 22pt × 22pt squircle(6pt 圆角),服务识别色填充,白色 logo 14pt 居中。详见 设计风格 §11.2。 |
| 服务名 + plan(VStack,line-height 1.08) | `Codex` 13pt .semibold kerning -0.1<br>`OpenAI · Plus` 11pt secondary opacity 0.75(按 `email · plan` 拼接,隐私模式隐藏 email,兜底品牌名) |
| Spacer | — |
| 服务状态圆点 | 6pt 圆,贴 Spacer 后,行尾。颜色按 statuspage indicator(none 绿 / minor 黄 / major 橙 / critical 红 / maintenance 蓝),`unknown` 或未拉到时不显示。受设置项 `showServiceStatus` 控制,tooltip 显示 statuspage description + 相对更新时间。 |

#### 1.4.2 Body row(HStack,alignment center,gap 10pt,marginTop 12pt)

**左栏:主要额度大数字 + 动态窗口标签**(VStack,center,spacing 4,width 72pt)

- 第一行:HStack(firstTextBaseline,spacing 0),`42` 32pt .semibold monospacedDigit kerning -0.8 + `%` 16pt .semibold(状态色;无快照时 `.secondary` 显示 `--`)。
- 第二行:固定短标签,不随 App 语言切换,9pt .semibold kerning 0.5 .quaternary:五小时额度统一显示 `5HOUR`;周额度 Codex 显示 `WEEKLY`、Claude 统一显示 `ALL`;Antigravity 主条/副条带官方组名(`displayName` 驱动):主条 `GEMINI 5H`、副条 `GEMINI WK`,辅助行 `CLAUDE 5H` / `CLAUDE WK`;`modelWeekly` / `unknown` 显示模型名(空则 `MODEL` / `CURRENT`)。
- 宽度固定为 72pt 居中对齐，与次要额度行标签严格等宽，确保所有卡片主/次进度条左端点垂直重合。
- 状态色规则按 设计风格 §4.3。

**右栏:进度条 + reset / 费用两行**(VStack,leading,spacing 8,flex 1)

1. **ProgressBar**:高 7pt(圆角 3.5pt),状态色填充 + `.quaternarySystemFill` 轨道。进度 = `primaryWindow.remainingPercent / 100`。
2. **文本行 1**(HStack,spacing 0):
   - 左:`ResetTimeText` 紧凑格式 `2h18m`(11pt .medium primary),悬停行内切换相反格式(剩余时长 ↔ 具体时刻,当天 `HH:mm`,跨天 `MM-dd HH:mm`);无重置时间显示 `—`。
   - 右:`today · 今日` 与 `this week · 本周` 两项费用,`$12` 11pt .medium primary monospacedDigit(取整美元,`<$1` 用于 0 ~ 0.99)+ 10pt quaternary 标签,HStack spacing 10。Codex / Claude 取本机日志聚合，Cursor 汇总已成功拉取的远端计量数据；有缓存缺口时后台补拉并保留当前金额，仅完全没有远端快照时显示 `—`。
3. **文本行 2**(HStack,spacing 0):
   - 左:`reset · 重置` 9.5pt quaternary。
   - 右:`cost · 花费` 9.5pt quaternary。

**Cursor 特例**：主额度固定使用 `cursor-total` 并显示标签 `TOTAL`；`cursor-auto` 与 `cursor-api` 作为缩小额度行显示 `AUTO` / `API`，不映射为 Weekly。今日 / 本周费用复用既有位置与样式，仅数据来源改为远端计量。`isUnlimited == true` 时左栏值位显示 `∞`（与 Codex / Claude 的「数值 + 窗口标签」同构），标签固定 `UNLIMITED`，右栏不渲染进度条、只保留重置时间与费用行；同一个意思不重复第二遍。

#### 1.4.3 次要额度行（compactLimitRow，HStack, gap 10pt）

- **左侧标签**：9pt .semibold kerning 0.6 .quaternary，宽度固定 72pt（`.leading` 对齐），与主行左栏对齐。
- **中部进度条**：`ProgressBar` 高 2.5pt（圆角 1.25pt），自适应吃满剩余宽度。
- **右侧百分比**：10.5pt .medium monospacedDigit，宽度固定 32pt（`.trailing` 对齐）。
- **右侧重置时间/状态**：10.5pt quaternary，宽度固定 52pt（`.trailing` 对齐），保证不同字符长度（如 `6d1h` vs `5d23h` vs `尚未使用`）下细进度条右端点完全平齐。

#### 1.4.4 Block 间分隔

- 相邻 Provider 之间:0.5pt 横线,**左右各 inset 16pt**。
- 最后一个 block 之后无 footer,由系统 `NSPopover` 圆角承接底边。

#### 1.4.5 空状态 / 错误状态

- `snapshot == nil` 且 `error == nil`:左栏显示 `--` 32pt `.secondary`,右栏进度条空轨道 + reset 显示 `—`,无额外文案。
- `error != nil`:block 底部追加一行,`Color.orange` + 前置 `exclamationmark.triangle.fill` 图标(10pt),lineLimit 2。左栏按最后一次成功快照继续显示(`appState` 不清空快照)。Codex / Claude 沿用既有 `shortError`；Cursor 只显示通用“刷新失败”，不直出远端技术错误原文。其他账号行的错误态样式相同。
- 服务在 Settings 里被关闭(`showXxx == false`):**整个 block 不渲染**。
- 全部服务关闭:Popover 只显示 header + 中部两行占位 `No services enabled · 未启用任何服务`(12pt .medium secondary)+ `Enable a service in Settings → Accounts · 到「设置 → 账号」开启`(11pt tertiary),垂直 padding 24。

### 1.5 Footer(已废弃)

> 原方案的 footer(左侧 `Open Statistics` 按钮 + 右侧 refresh + kebab)已**完全移除**。所有一级操作上移到 §1.3 Header 的图标行,刷新进度通过 header 刷新图标自身旋转 + disabled 表达。本节保留仅为历史参考,新实现不要再引入 footer。

### 1.6 交互

| 触发 | 行为 |
|---|---|
| 点 header `chart.bar.xaxis` | `mainTab = .stats` 后 `openWindow(id: "main")`,Popover 关闭 |
| 点 header `arrow.clockwise` | 触发 `appState.refreshNow()`,旋转 360° / 700ms;按钮不禁用(`refreshNow` 内部 in-flight 去重) |
| 点 header `gearshape` | `mainTab = .settings` 后打开主窗口 |
| 点 header `power` | `NSApp.terminate(nil)`,退出 App |
| 点 service block 任意空白 | 暂不响应(后续可定位主窗口到对应服务 scope) |
| 点 Popover 外 | Popover 关闭(系统默认) |
| Esc | Popover 关闭(系统默认) |
| ⌘R(focus 在 Popover) | 触发 refresh |
| 鼠标悬停任意图标按钮 | 浅灰圆角背景 + 手型光标(详见 设计风格 §11.9) |
| 鼠标悬停 reset 时间 | 行内切换相反格式:设置为剩余时长时显示具体时刻(当天 `HH:mm`,跨天 `MM-dd HH:mm`);设置为具体时间时显示剩余时长。hover 热区略大于文字本身,避免鼠标遮挡数字才触发。 |

### 1.7 数据来源对照

| UI 字段 | 数据源 |
|---|---|
| 主要额度百分比(左栏大数字) | `appState.quotaSnapshot(for: provider)?.primaryLimit?.window.remainingPercent`；Cursor Unlimited 改显示明确文本 |
| 主要额度标签 | `primaryLimit.kind` 映射为固定短标签：五小时 `5HOUR`；周额度 Codex 为 `WEEKLY`,Claude 为 `ALL`,不随 App 语言切换 |
| 主要额度 reset hint | 同上 `.resetsAt`；缺失时只延用尚未过期的同限额缓存值 |
| 次要额度 + 模型额度 | `secondaryLimit`（去重后）+ `auxiliaryLimits` + Claude `modelLimits`；Cursor 对应 Auto / API |
| today / this week 费用 | `UsageAggregator` 今日 / 本周 cost 总和（取整美元显示） |
| Header refreshed time | 所有已启用服务 `refreshState.lastSuccessAt` 取 max |
| 状态点 live/stale/offline | 现有 `headerState` 三态判定 |
| Plan 副标(`OpenAI · Plus`) | 账号邮箱 + `QuotaSnapshot.planType` / Provider 计划，隐私模式隐藏 email；Cursor 从只读 JWT 与额度快照取得 |
| 服务 tile logo | `Resources/Logos/` 下的 `codex.svg` / `claude.svg` / `antigravity.svg` / `cursor.svg` / `commandcode.svg` |

## 2. Floating HUD

### 2.1 整体规格(默认变体:Two-row pill)

| 项 | 值 |
|---|---|
| 宽 | auto,最小 168pt |
| 高 | auto(两行 pill 约 50–60pt) |
| 圆角 | 14pt |
| 材质 | `windowBackgroundColor` 0.55 实色层 + `.popover` material(`NSVisualEffectView`,`blendingMode: .behindWindow`),三层叠加 |
| 背景 | 实色压底 + `.popover` 毛玻璃 + 0.5pt hairline 描边(`Color.primary.opacity(0.12)`),见 设计风格 §12.3 |

### 2.2 内容结构(variant 1)

VStack,spacing 7pt。每行结构如下:

```
[●]  ████████░░░░░░░░░░  [42%]
[●]  ███████████████░░░  [78%]
 18pt    flex,4pt bar     34pt
```

| 元素 | 规格 |
|---|---|
| 左侧 logo tile | `ServiceTile` 18pt 圆角 5pt,服务色填充 + 内嵌 logo 12pt(`codex.svg` / `claude.svg` / `antigravity.svg` / `cursor.svg` / `commandcode.svg`),logo 加载失败时回退字母 |
| 中间 bar | 高 4pt,圆角 2pt,状态色填充 + `.quaternarySystemFill` 轨道,flex 1(最小宽 56pt) |
| 右侧百分比 | 13pt .semibold tabular kerning -0.3,状态色(见 设计风格 §4.3),最小宽 34pt 右对齐 |
| 行内 spacing | 8pt(tile / bar / 百分比 三段之间) |

进度 = `primaryLimit.window.remainingPercent / 100`。bar + 文字均按 设计风格 §4.3 四档状态色显示；Cursor Unlimited 空出 bar 位保持三段对齐，右侧只显示 `∞`，不使用 100% 代替，也不另加文字。

## 3. Statistics 主窗口

系统级入口：从 Dock、应用程序、Launchpad 或 Raycast 启动 / 重新打开 CCBar 时，主窗口置前并切到 Statistics；`SMAppService` 开机自动启动保持静默，首次启动仍优先显示 Onboarding。

### 3.1 整体规格(默认视图:Overview)

| 项 | 值 |
|---|---|
| 宽 / 高 | 默认 1600pt × 1100pt,最小 1040pt × 520pt,可调 |
| 圆角 | 12pt(系统 Window) |
| 顶栏 | 无系统 toolbar;粒度 + 时间范围两个 segmented Picker 在 Overview 画布顶部右对齐(见 §3.2) |
| 布局 | Sidebar(200pt) + Main canvas |

### 3.2 Top bar(Overview 画布顶部)

统计口径是**两级**的:粒度(日 / 周 / 月)是上级,决定「一个统计单元」是一天、一周还是一个月;时间范围是下级,只能在当前粒度自己那组范围里选。整页所有面板(KPI 行、Token 拆分、按服务、按模型、按提供商、用量柱状图)都按所选范围聚合,柱状图按粒度分桶。

- 无系统 `toolbar`(主窗口只有 TabView)。Overview 画布顶部一行右对齐,两个 SegmentedControl 并排:
  - 扫描中显示 `ProgressView` + `Recalculating usage… · 正在重新计算用量…`(11.5pt secondary),否则不占位。它**独占左侧剩余空间并在其中右对齐**(取代原来的 Spacer),视觉上紧贴粒度控件左边;不能当成 HStack 的普通成员夹在 Spacer 与两个 Picker 之间——它随后台扫描自行出现 / 消失,夹在中间会把右对齐的控件整体推着左右平移。
  - **粒度 SegmentedControl**(左,3 个段):`Day / Week / Month`,对应 `日 / 周 / 月`。

#### 3.5.2 变动折线图

5H 显示一个「今天」区段；周视图在同一张图和同一张表中展示「当前周期」与「上一周期」两个区段。周期区段通过顶部范围行和折线断点区分；无数据时显示居中 `No data for this window · 该窗口暂无数据`。

- X 轴:不固定为整段周期，按选中窗口内实际数据的首尾采样时间自适应，两端各留 4% 跨度的余量；只有一个点或零跨度时用固定余量兜底(5H 15 分钟、周视图 30 分钟)。5H 标签 `HH:mm`，周周期标签 `MM-dd HH:mm`，两者都按 `desiredCount: 5` 自动稀疏刻度。
- Y 轴:选中窗口剩余百分比,固定 `0...100`,刻度 `0 / 20 / 50 / 80 / 100`。当前周期和上一周期在同一张图中按额度窗口独立绘制，跨周期重置不连接成同一条曲线；窗口类型改变时也重置该系列曲线基准。
- 折线按额度窗口分段(`series = windowIndex`):5H 的一天横跨约 5 个 5H 窗口,窗口边界处断线,不把上一窗口的低点与新窗口的高点连成假回升斜线;点与表格仍保留全部数据。
- 线:账号服务识别色,2pt。
- 点:真实变动事件和当前周期最新成功采样。最新采样的 delta 为空，不把跨窗口重置伪造为消耗；颜色按剩余百分比走 `statusColor`，其中 normal(>50%)档在图表内比全局中性灰加深一档(浅 `#56565A` / 深 `#AEAEB4`)，保证浅色模式下可读，点尺寸 40pt。
- 网格线 `.secondary.opacity(0.18)`、轴标签 `.secondary`,不再用最浅的 quaternary / tertiary 档。
- 图上保留真实变动点；即使本次刷新与上次同值，也至少显示当前周期最新采样，确保刷新状态不滞留在上一周期。

##### 开关层级语义(所有 Provider 通用)

这里的 Accounts Toggle 是 Provider **总开关**(`ProviderDisplaySettings.enabled`),菜单栏与悬浮窗开关是它的**子开关**,不是平级:

| 位置 | 存储 | 生效条件 |
|---|---|---|
| Accounts(总开关) | `enabled` | — |
| 菜单栏 | `menuBar` | `enabled && menuBar`(`effectiveMenuBarVisibility`) |
| 悬浮窗 | `floatingHUD` | `enabled && floatingHUD`(`effectiveFloatingVisibility`) |
| Popover | — | `enabled` |
| 统计服务 | `usageServiceVisibility`(**独立**,不受 `enabled` 约束) | 见 §Stats services |

也就是说「可独立控制」指的是:**菜单栏与悬浮窗彼此独立**(可以只在菜单栏显示、悬浮窗不显示),以及**统计服务独立于额度 Provider**(可以只看 Cursor 统计、不显示 Cursor 额度卡片)。它**不**表示子开关能绕过总开关——Provider 关闭时,该服务不会出现在菜单栏 / 悬浮窗 / Popover 的任何位置。Codex、Claude Code、Cursor、Command Code 四者行为完全一致，均支持独立的菜单栏与悬浮窗展示开关。
